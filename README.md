# Whispr

O **Whispr** é um sistema de chat em tempo real, construído com o ecossistema .NET e hospedado na nuvem Azure. Este é um projeto de longo prazo focado em estudar e explorar boas práticas de desenvolvimento e DevOps.

---

## 🔥 Principais Funcionalidades

* **Comunicação Instantânea:** Chat público em tempo real usando **SignalR** (WebSockets).
* **Suporte Multimídia:** Envio de textos, reações, imagens com preview inline e áudios com player embutido.
* **Comandos de Barra:** Recursos dinâmicos como o comando `/stock` (busca cotações sem poluir o banco de dados).
* **Painel Admin:** Gerenciamento de usuários (banimento), logs de comandos executados e controle de moderação.

---

## 🛠️ Tecnologias Utilizadas

### Frontend & Backend
* **.NET 10+** (C#)
* **Angular 21+**

### Infraestrutura em Containers
* **Postgres:** Persistência de dados relacionais.
* **PgAdmin:** Interface gráfica para gerenciamento do banco de dados
* **Seq:** Visualização de logs

### DevOps & Qualidade
* **CI/CD:** Pipelines automatizados via **GitHub Actions**.
